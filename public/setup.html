Set up free accounts.

For the website owner: connect a Supabase Free project to your Cloudflare Pages site. Visitors will use a username and password, with no email or Google sign-in.

  1. Create a Supabase Free project. Open Supabase, choose the Free plan, and create a new project named media-thingy. Choose a database password and wait for the project to finish starting.
  2. Set up the database and private song bucket. Click the button below, open Supabase’s SQL Editor → New query, paste the copied SQL, and click Run. It creates the required tables, password functions, and private storage bucket automatically.

    Loading the setup SQL…

    Show the SQL to copy manually
  3. Find two project values. In Supabase, copy the project URL from Connect → App Frameworks or Settings → Data API. Under Settings → API Keys → Legacy API Keys, reveal and copy the service_role key. Keep that key private.
  4. Add them to Cloudflare. Open Workers & Pages → your Pages project → Settings → Variables and Secrets. In Production, add:
    Name Value
    SUPABASE_URL Your project URL, like https://example.supabase.co
    SUPABASE_SERVICE_ROLE_KEY The private service_role key; save as a Secret/encrypted value

    These belong in Cloudflare’s server settings. Do not put the key in a VITE_ variable, source code, this page, or chat.

  5. Redeploy your site. Under Cloudflare Deployments, retry the latest deployment from main. The build command stays npm run build, output directory dist, and root directory blank. Leave both services on their Free plans; this setup does not use D1, R2, or paid password hashing in Cloudflare.
  6. Make your music account. Return to the app, refresh, and open Settings → Your account → Create account. Add a song, then sign in in another browser to check it returns. In Settings, Copy this device’s songs to account imports songs already saved at this website address.

Supabase Free has a shared storage and transfer allowance. This app caps saved file usage at 950 MB across all accounts, leaving some headroom within the 1 GB allowance. Supabase’s monthly transfer allowance is also shared; inactive Free projects can pause. Use a new, dedicated project and do not enable paid add-ons.
